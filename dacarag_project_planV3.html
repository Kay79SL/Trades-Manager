WhyVector search handles semantic paraphrase ("damp patch on ceiling" → "leaking pipe") that keyword search would miss entirely. Atlas Vector Search means no separate vector DB — same Mongo cluster, one less moving part.
  1. Ask Claude to write ingest\embed_chunks.py — for each email body, job_type description, and item name, generate a 384-dim vector with sentence-transformers and store in a chunks collection
  2. Run the embedder
    3. python ingest\embed_chunks.py
    First run downloads the model (~80MB) and is slow. Subsequent runs use the cached model.
  3. In Atlas: navigate to your cluster → Atlas Search → Create Index → JSON Editor
  4. Paste this index definition (collection: chunks, name: vector_index)
    5. {
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 384,
      "similarity": "cosine"
    },
    { "type": "filter", "path": "chunk_type" },
    { "type": "filter", "path": "trade" }
  ]
}
  5. Wait for the index status to turn "Active" (typically 5–10 minutes)
  6. Test similarity search with a sample query
